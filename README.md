# Landing-page-HTML-CSS-JavaScript

Este repositório reúne projetos de landing pages desenvolvidos para praticar criação de interfaces com HTML, CSS e JavaScript. O foco está em estruturação de páginas, estilos, layouts e design responsivo.

O repositório faz parte de uma **jornada de 41 projetos para o GitHub**. Atualmente, contém o projeto número 2 dessa jornada:

## Projetos

### 2. Landing page Starbucks

Landing page inspirada na Starbucks, desenvolvida como exercício de acompanhamento de uma videoaula no YouTube com **Larissa Kich**. O projeto apresenta bebidas, informações sobre a marca e novidades, com layout responsivo e menu mobile.

- [Ver apresentação, capturas de tela e instruções do projeto](./Landing-page-starbucks/README.md)
- [Abrir a página da landing page](./Landing-page-starbucks/index.html)
